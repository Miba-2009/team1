# AI Webアプリ企画例

このファイルは、制作前に考える内容の例です。文章をコピーして、自分たちの企画へ書き換えてください。

## 1. 課題を見つける

身近な生活や学校で「面倒」「分かりにくい」「時間がかかる」と感じることを書き出します。

- 勉強を始めても、何から取り組めばよいか迷う
- 長い説明文を読むのに時間がかかる
- 分からない言葉を調べても、説明が難しい
- 自分に合う復習問題を作るのが大変

## 2. 課題を1つに絞る

全部を一度に解決しようとせず、ハッカソン中に試せる大きさへ絞ります。

### 今回取り組む課題

> 勉強したい内容は決まっているが、最初の学習計画を作るのが難しい。

### 主に使う人

> 定期テストの勉強を始める高校生。

## 3. 解決方法を考える

### アプリの案

> 教科、勉強できる時間、苦手な内容を入力すると、AIが今日の学習計画を作るアプリ。

### 必要な入力

- 教科
- 勉強できる時間
- 苦手な単元
- テストまでの日数

### AIにお願いすること

- 入力された条件を整理する
- 無理のない順番に並べる
- 各学習項目の目安時間を付ける
- 高校生にも分かりやすい文章で回答する

### 表示する結果

- 今日やること
- それぞれの目安時間
- 最後に確認するチェック項目

## 4. 作る機能を決める

### 最初に完成させる機能

- 条件を入力するフォーム
- AIへ条件を送るボタン
- AIの回答を表示する場所
- 入力漏れを知らせるメッセージ

### 時間があれば追加する機能

- `DB.add()`で学習計画を保存する
- `DB.list()`で過去の計画を一覧表示する
- 完了した項目へチェックを付ける
- 教科ごとに色を変える

## 5. AIへ送る文章を考える

例:

```text
あなたは高校生の学習を支える先生です。
教科: 数学
勉強時間: 60分
苦手な内容: 二次関数
テストまで: 7日

今日取り組む内容を3段階に分け、各段階の目安時間を付けてください。
高校生に分かりやすい日本語で答えてください。
```

## 6. 実装できるか確認する

- Default/index.htmlに必要な入力欄を追加できるか
- Default/style.cssでスマートフォン表示も確認できるか
- Default/js/app.jsから`AI.chat()`を呼び出せるか
- 保存が必要なら`DB.add()`と`DB.get()`で実現できるか
- 個人情報や秘密情報をAIやDBへ送っていないか

難しすぎる機能は後回しにし、まず「入力 → AIへ送信 → 結果表示」の1本を完成させます。
